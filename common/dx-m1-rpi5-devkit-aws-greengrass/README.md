# DEEPX DX-M1 Edge AI Development Kit with Raspberry Pi 5 — AWS IoT Greengrass

This repository provides the **Getting Started Guide for AWS IoT Greengrass** for the **DEEPX DX-M1 Edge AI Development Kit with Raspberry Pi 5**, which pairs a Raspberry Pi 5 (8 GB) host with the DEEPX DX-M1 AI accelerator (up to 25 TOPS) over PCIe Gen 3.

📖 **[Getting Started Guide for AWS IoT Greengrass](./Getting_Started_Guide.md)**

The guide walks you through assembling the kit, installing the AWS IoT Greengrass Core software (v2) on Raspberry Pi OS (64-bit), and deploying your first Greengrass component.

## About the Kit

| Item | Specification |
|---|---|
| Host board | Raspberry Pi 5 (Broadcom BCM2712, quad-core Arm Cortex-A76, aarch64) |
| AI Accelerator | DEEPX DX-M1 (M.2), up to 25 TOPS @ 1–5 W |
| Memory | 8 GB (host) + 4 GB LPDDR5 (DX-M1) |
| Accelerator interface | PCIe Gen 3 x1 (M.2 base HAT) |
| OS | Raspberry Pi OS (64-bit, Debian 13 "Trixie") |
